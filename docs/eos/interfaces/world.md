# World resources

[中文](../../../docs_cn/eos/interfaces/world_cn.md) · [EOS interfaces](README.md)

The earlier world-resource and fusion schemas are target designs. The current graph does not publish a world resource; its read-only return payload is `arm_monitor_state@v0.2`. See [arm control](arm-control.md), [arm monitor](arm-monitor.md), and [owner lifecycle](owner-health.md) for the implemented contracts. Future direction belongs in the [EOS architecture](../design/architecture.md#future-architecture).
