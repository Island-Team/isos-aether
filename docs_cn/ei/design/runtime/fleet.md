# EI 多后端运行

[English](../../../../docs/ei/design/runtime/fleet.md) · [架构](../architecture.md) · [链路](../io/link.md)

`modes.toml` 的 fleet profile 可声明多个带稳定别名的 EOS 后端。每个后端包含 `id`、名称、简介和网关端点。配置示例见英文伴随页；地址在本地配置中选择，不能由模型动作更改。

## 发现与寻址

链路针对每个别名获得当前 EOS 身份、版本、启动与健康状态，以及硬件 profile、型号、供应商、描述、设备 ID、类别、部件、运行元数据、世界资源和带版本/数值限制的原语描述。资源与原语按别名和设备 ID 索引，因此不同机器人或同类设备不会混淆。动作目标必须明确包含 `robot_id`、`device_id`、原语及参数；缺失或歧义目标在传输前拒绝。

## 协同与安全

任务协调使用当前发现代和设备健康来选择候选目标。安全门对每次动作重新验证精确能力、设备限制及当前状态；一台后端断连不能把另一台的结果当成成功。紧急停止建立机群屏障，并尽力通知所有已发现设备与端点。每个失败独立记录，锁存不会因部分成功而清除。

## 当前限制

聚合场景投影仍以第一个端点为来源。EOS 发现不能推导区域或站点的可达性；租约是 EI 的协同约束，不是物理锁或 EOS 准入替代品。
