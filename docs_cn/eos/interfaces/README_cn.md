# EOS 接口

[English](../../../docs/eos/interfaces/README.md) · [EOS](../README_cn.md) · [架构](../design/architecture_cn.md)

EOS 在图格式 `0.2.0` 中负责到模拟机械臂的控制路径及其观测返回路径。[机械臂控制契约](arm-control_cn.md)定义激活、增量和限值。[机械臂监控契约](arm-monitor_cn.md)定义类型化返回路径和私有读取路由。IsOS 负责保存图、软件包检查、Apply 和部署状态。[所有者生命周期](owner-health_cn.md)定义 Run、Status、Stop 和工作进程故障。[设置交换](setup-v1_cn.md)定义身份、目录、验证和渲染。[快速入门](../start/quick-start_cn.md)按操作顺序说明。
