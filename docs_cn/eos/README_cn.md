# EOS 文档

[English](../../docs/eos/README.md) · [文档索引](../README_cn.md) · [约定](../island/conventions.v1.4.0_cn.md)

EOS 执行已应用的 IsOS 图，负责已声明的硬件适配器、实时健康状态、Dispatcher 准入以及直接拥有的 MuJoCo 子进程。

- [入门](start/README_cn.md)：构建、配置、启动、检查、停止和排障。
- [接口](interfaces/README_cn.md)：外部消费的载荷、控制、仿真器、适配器和诊断契约。
- [架构](design/architecture_cn.md)：所有权与生命周期总览，并链接运行时和节点族设计。
