# IsosUI 0.x 交付记录

本记录追踪 IsosUI 工作台交付。首次使用先显示所属方状态，再显示本次运行的因果日志。

[English](../../docs/isosui/todo.md) · [设计](design_cn.md)

1. **已完成——图与目录读取。** 当前图与所选目录修订限制编辑和 Invoke。见 U01 #40 和所选目录 #44。
2. **已完成——U01 表单与选择器。** 元数据表单及可搜索场景／设备选项保留不可用 ID，并阻止无效 Apply。见 U01 #40。
3. **已完成——U02 连线。** 精确 IsOS 诊断、已路由优先级／频率编辑，以及仅设计／固定路由的无障碍标签由 U02 #41 覆盖。
4. **已完成——U04 节点信息卡。** 悬停、焦点和触摸展示类型与实例描述、端口、单位及所属方报告的健康，不妨碍图编辑。见 U04 #42。
5. **已完成——U03/U04 工作台。** 独立控制、监视、Vision 和日志面板保存有界布局及 Stop 权限；每个受支持活动原语绑定有一个图解析目标、类型化 `primitive_typed` 控件和关联结果跟进。图连线不执行命令。见 U04 #42、U03 #43 和刷新 #45。
6. **已完成——本次运行日志。** Home 使用 IsOS JSONL 游标、固定首事件锚点、缺口提示及来源筛选，并将命令结果与日志区分。见 [P07 UI 契约](interfaces/log-cursors_cn.md)。
7. **所有者检查已记录。** 中英文首次使用、无障碍交互、Node 22/npm 10 测试及本地／托管构建见 Q03 所有者证据。封存的 Q03 final-17 选定回放和 Q04 final-5 合并后回放通过各自精确输入验证。Final-5 在回环地址模拟托管 Origin；这不证明真实公网 HTTPS 首次使用。当前统一产品发布方式见[产品发布指南](../island/release_cn.md)。
