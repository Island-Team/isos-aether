# 节点图加载与状态展示

浏览器记住上次打开的图库文件名。打开工作台时优先选择该文件，否则选择 `demo` 或首个可用文件。若记住的文件已消失，界面会提示回退选择；若图库已空或当前文件消失，保存时要求新文件名。保存使用打开文件时的修订校验，并提示会替换同名文件。应用选择图库文件的精确已保存修订并重新生成所有者配置；保存并运行依次执行保存、应用、运行。

IsOS 拥有已保存的节点图字节、修订、目录、软件包收据、就绪状态和进程状态。浏览器只保存草稿和所有者报告的展示状态。编辑器仅在所选节点图与目录快照的 `graph_revision` 一致时渲染并允许编辑；不支持或修订不一致的快照保持只读。

打开节点图及明确点击重新载入时，等待所选节点图和目录快照。快照通过修订与编辑代数检查后即可显示画布。节点集、进程状态和核心就绪状态随后独立加载；其中一项延迟或失败不会把有效节点图标为不可用。迟到的可选响应不能覆盖较新的节点图请求、编辑代数或状态轮询。明确重新载入期间保留原画布；本地编辑或更新的目录请求会丢弃迟到的快照。

首页在打开、明确点击刷新以及修改后执行一次完整的节点图、软件包、设置、就绪状态和进程刷新。每五秒的后台轮询只请求进程状态，且最多保留一个在途请求。迟到的轮询不能覆盖较新的完整刷新或部署操作。Run 和 Apply 仍须在发送所有者请求前向 IsOS 复查所选节点图修订与目录权限。这些界面规则不改变 IsOS 的验证、Apply 或命令准入。
