# IsosUI 架构

[English](../../docs/isosui/architecture.md) · [阅读地图](README_cn.md) · [当前设计](design_cn.md)

当前工作台呈现 IsOS `0.2.0` 节点图格式和各所有者目录。画布几何信息保存在浏览器中，图设置由 IsOS 保存，网络请求集中在 `ui/src/services/`。UI 不负责执行器准入。控制与监视界面使用两条独立的所有者路由：用户操作发送一次带运行围栏的命令，观测数据则独立采样和转发。IsOS 管理运行与修订围栏；EOS 决定是否准许运动。关闭监视面板不会停止 EOS 的本地采样。

## 未来目标

**目标设计——尚未实现。** 当软件包所有者契约声明身份、校验和生命周期后，选择器框架可扩展到模型权重等其他已验证的软件包资源。UI 将显示稳定的目录 ID，而不是接受任意路径。此目标不表示当前工作台支持模型执行。

**目标设计——尚未实现。** 未来的监视界面可展示异步观测路由各阶段的延迟及丢样诊断。所有者必须先定义计数器和运行范围语义，UI 才能把这些值作为权威数据呈现。当前 UI 显示最新状态、新鲜度和故障／停止状态。
