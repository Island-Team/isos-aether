# 首次使用：图与工作台

[English](../../docs/isosui/usage.md) · [设计](design_cn.md) · [TODO](todo_cn.md)

Q03 验证设计 固定选定版本的浏览器安装回放和初始界面基线。当前产品分发方式见[产品发布指南](../island/release_cn.md)。安装统一的 IsOS 产品包；下面的源码构建步骤仍适用于开发。

## 当前路径

当前按钮到机械臂演示：载入当前节点演示，保存后运行。只有已保存修订正处于运行中时，按钮节点的 **触发** 控件才可用。每次点击向 IsOS、EI、EOS 发送一次激活事件，最终到达六关节模拟机械臂。节点显示事件 ID、返回状态和关节位置。若结果不确定，请保留显示的 ID 以检查日志；界面不会重发该事件。

点击节点上的 **配置**，在节点旁的卡片中编辑必填的基本值与选择器。展开 **高级设置** 可查看可选设置和目录默认值。只有修改后才保存覆盖值；**恢复默认** 会删除覆盖值。侧边检查器保留完整的节点、端口和诊断详情。键盘可通过焦点及 Enter 或空格操作，Escape 关闭卡片；触控使用相同按钮。

Graph 会打开浏览器上次选择的图库文件；若没有记录，则选择 `demo` 或首个可用文件。通过 Graph → 高级操作 → **图库文件** 切换文件，未保存修改时会先确认。**保存文件**按精确修订写回当前绑定的文件；界面提示同名文件会被替换。若图库已空，或当前文件在编辑期间消失，保存时会要求新文件名。**应用节点图**或**保存并运行**先验证草稿，再保存图库文件，并应用该文件的精确修订后运行。若类型目录无法加载，画布仍从已保存路径显示层和组，并明确提示端口详情不可用。

1. 安装 Node.js 22 和 npm 10，在本仓库运行 `npm ci` 和 `npm run build`，并在 IsOS 中选择生成的 `dist/local`。也可用 `npm run dev` 在 `127.0.0.1:16001` 启动独立前端；图编辑和实时控制仍需要 IsOS 环回 API 和其管理的 EOS 所有者。
2. 运行 `isos serve`，打开 `/en/isos` 或 `/cn/isos`。Home 显示管理器设置、已安装包收据、核心就绪状态、进程状态与全部来源日志。API 离线应显示阻塞原因，而非空图。
3. 在 IsOS 中安装或链接精确的 `island/mujoco-sim@0.1.1`。在 Graph 选择 `sim-hardware` 节点集，预览新增节点并选择场景。在 Graph 中按 **core → layer → group → node type** 浏览。通过 `/node-options` 中 `isos/eos_process/mujoco/simulator` 的可搜索选项选择场景，再按各相机／底盘／机械臂的精确 `node_path` 选择设备。一次设备选择同时写入 `adapter.settings.device_id` 和 `adapter.settings.simulator_node`。
4. 选中节点，分别阅读注册类型描述和可编辑的实例描述，并配置类型声明的字段。搜索所有者提供的选项名称与说明，查看已保存但不可用的 ID 及修复原因。更改场景或软件包后，等待当前草稿的设备选项刷新，再尝试应用；连接兼容的输出和输入端口，然后在“高级操作”中选择 **Check graph**。若连线高亮，选中它：检查器显示来源/目标类型 ID、IDL 字段单位，以及该输入端口的 IsOS 拒绝代码、路径和原因。“诊断”区域保留完整服务器结果。修正端口或节点设置后再次检查；修改草稿会使上次检查结果过期。检查器里的部署状态与节点实时健康分开，后者可在 EOS 监视器查看。确认检查通过后，再用 Graph 主操作保存并运行修订。由服务器验证、应用图；浏览器草稿本身不能控制 EOS。

7. 通过 IsOS 停止部署。升级时安装精确的新包版本，预览节点、检查图、应用新修订并重启；保留经验证的软件包收据以便恢复。

若归属方目录读取较慢，等待 EOS 控件当前刷新完成；五秒后台定时器不会取消正在进行的读取。点击工作台 **刷新** 可请求新的归属方快照；在新的已保存节点图、所选目录、进程状态和 EOS 发现结果一致前，Invoke 保持禁用。所选目录不可用或修订不匹配时，控件保持只读并显示原因。

仓库根目录的 [README](../../README_cn.md) 记录开发命令和构建输出。包安装和进程操作由 IsOS 负责。

## P07 日志导航

包或 Apply 失败后打开 Home 日志。面板向 IsOS 请求 `view=current`，在来源、级别、节点和关联筛选器上方显示管理器会话中的首条包／Apply 故障。尚未收到该事件时显示锚点待定；空列表不表示成功。IsOS 准入部署运行后，面板切换到该运行的首条就绪或故障事件，再显示后续详情行。停止、进程退出或管理器重启后仍选择该运行，直至 IsOS 准入下一次运行。实时就绪及保存／活动修订以 Home 状态为准；日志只解释其发生时的事情。


筛选后空页若游标推进且无诊断，仅表示暂时没有匹配详情行，不是缺口。状态报告 `run_id_state:unavailable` 或当前日志返回 `log_scope_unavailable` 时，将旧行标为过期，身份恢复期间以实时状态为准。Run 返回 `log_scope_publish_failed` 表示没有子进程启动，但持久运行记录可能仍幸存；解释范围前须刷新状态与当前日志。这两种情况都不允许 UI 自行选择管理器会话或宣称就绪。

## 当前 R07 模拟底盘控制

[R07 浏览器原语客户端](interfaces/control_cn.md)选择活动 `base.velocity` 绑定、显示图解析目标和有界 `body_velocity` 字段，并在操作员点击 Invoke 后通过 `primitive_typed` 发送命令。浏览器显示当前运行 ID 与保存／活动修订，使用关联结果读取确认 `InProgress` 的终态；发送超时不会重发命令。IsOS 部署 Stop 在 EOS 离线时仍可用。

### 使用受管理模拟底盘首次运行 R07

在 IsOS 中应用一个包含 `base.velocity` 原语绑定及唯一 `mock-cxx` 底盘目标的图，然后运行。打开 EOS，等待底盘状态及健康就绪。核对卡片显示的绑定和目标路径及 SI 限值，输入有界速度和有效期，再点击一次**调用**。卡片保留命令 ID，显示 EOS 精确状态，且只有 IsOS 确认同一运行和修订时才跟进 `InProgress`。自动读取暂停后可点击**刷新结果**。通过 IsOS 点击**停止部署**，再打开**当前运行日志**。日志视图不以命令 ID 预设筛选；命令 ID 留在卡片上供比对。

受管理模拟重放的首个命令返回 `OutcomeUnknown`；Stop 并重启后，卡片必须保留该所有者状态和 ID，同时显示**不适用于本次运行**。新运行中再次由操作员点击后，EOS 返回 `Rejected`，因为不确定的释放使运动仍被禁止。检查新命令的结果和当前运行日志；不要重发旧运动，也不要把模拟 Stop 响应当作 MuJoCo 物理停止证明。EOS 检出目录中被忽略的 `data/test/20261102-r07-cross-owner-live/SUMMARY.md` 记录了精确图、修订、响应体和命令。

点击**停止部署**后，在 IsOS 响应前显示**正在停止…**。Stop 提示与实时状态分别检查：**停止已确认**需要相同运行 ID 和 `terminal.outcome:"confirmed"`；**停止结果未知**包含固定原因代码，应查看当前运行日志。**停止未获确认**表示终态响应缺失、为 null、损坏或属于另一运行。若从未运行且 `run_id_state:none`，显示没有需要停止的受管运行。**停止响应不可用**表示未收到响应；再次操作前检查更新的 IsOS 状态和日志。状态刷新失败不改变显示的 Stop 结果。点击后旧 EOS 命令结果保持隔离，包括迟到响应。

若 IsOS 明确拒绝 Stop，告警显示**IsOS 拒绝停止**及所有者消息。即使子进程已回收，`terminal:null` 仍是未确认；重复的子进程结果不能确认 Stop。

## 当前 M4 工作台交互




鼠标在节点上停留约半秒后，在指针旁显示浮动信息卡；键盘聚焦或点击信息按钮可立即打开。点击或拖动节点时，该节点位于相邻节点之上。分别显示注册类型描述与实例描述，以及层级、端口和单位；仅在所属核心报告时显示实时健康。将卡片限制在视口内，提供触摸入口，同时不妨碍拖动节点和编辑连线。

每条连接可编辑 `priority`（nice 值 `-20..19`，默认 `0`）及可选 `frequency_hz`（有限正数，表示传输频率上限）。检查器根据 IsOS 验证结果编辑。正常缩放和键盘焦点提示都显示两个值；图例将优先级、频率与传输方式、负载类型分别解释。端口形状表示通道，端口颜色表示准确的负载类型，连线图案表示频率上限，连线颜色表示优先级（红色较高，蓝色较低）。静态拓扑端口使用虚线边框，不承载负载。仅当 IsOS 确认归属方支持运行时路由后，界面才提供实时连接。优先级只影响调度，不绕过 Dispatcher 安全准入。

工作区让**控制**、**监视**、**Vision**、**日志**面板分别停靠或浮动。浮动面板有拖动、调整大小、焦点顺序、关闭/停靠操作、有界视口和本地布局保存；恢复时把几何位置限制在当前视口。窄屏按顺序叠放，保留 Stop 操作和重要的连接或修订警告。普通消息短暂显示，并留在日志的浏览器分区。工作页面采用紧凑对齐的行、透明或轻微半透明背景；视觉概览页面可用更宽的间距。两类页面共享参考 Island-web 的样式 token、克制的边框、可见键盘焦点、所有布局中约 30 px 高的控件。

完整 U04 原语演示按以下顺序使用：查看节点，检查并应用图，等待 EOS 就绪。在 EOS 控制面板中选择一个活动原语绑定并查看从图解析出的唯一目标；要改变目标须编辑图并 Apply。面板显示两种节点描述，并按所属契约显示类型化原语字段。通过现有回环 `primitive_typed` 桥接调用。先显示浏览器本地的发送状态，再根据关联响应显示精确的 `Completed`、`Failed`、`Cancelled`、`Rejected`、`InProgress` 或 `OutcomeUnknown`；`InProgress` 在经授权结果读取确认前保持未完成。当前运行日志与实时健康分别呈现；仅当 EOS 所有者事件提供对应的有效 ID 时按关联筛选日志。图上的连线本身不表示命令已经执行。通过 IsOS 停止。

### 连线服务质量检查器

选择连线后点击**检查节点图**。检查器依据 IsOS 返回的精确来源指针显示路由类别。仅当 IsOS 确认连线已声明路由、允许 QoS 且不是固定连线时，才能编辑优先级和频率上限。nice 优先级为 -20（最高）至 19（最低）的整数，有效权重为 `20 − 优先级`；频率上限留空表示无限制。生产者预期频率仅是单独提示。输入后按 Enter 或离开字段提交草稿。每次编辑都会清除先前的路由授权；再次编辑 QoS 前需重新**检查节点图**。无效值阻止保存和保存并运行。Apply 前会重新请求 IsOS 检查精确草稿；拒绝或过期检查不会发送 Apply。仅设计用途与固定连线仍可查看，但不能编辑 QoS。

## U04 节点卡与原语控制

鼠标在 Graph 节点上稍作停留、键盘聚焦或轻触信息按钮，即可查看独立的目录类型与实例描述、类型化端口以及 EOS 所有者报告的健康状态。Escape 或关闭按钮退出视口内的信息卡。在 EOS 中，每个受支持的活动 `@v0.2` 底盘或机械臂绑定都有独立控制卡。检查图解析的唯一目标、原语、单位和限值；更改目标须编辑并 Apply 节点图。等待已知 IsOS 运行、相等的保存／活动修订及 EOS 就绪健康状态。仅点击一次调用。浏览器显示发送中时保留命令 ID，随后显示 EOS 的精确状态。`InProgress` 仅用同一 ID 经授权的公开结果读取跟进；丢失响应绝不重新提交。EOS 控制失败时仍可通过 IsOS 停止部署。参见 [U04 契约](interfaces/control_cn.md)。

## U03 首次使用：工作区面板

打开节点图，通过工作区工具栏分别显示控制、监控、视觉和日志面板。每个面板都可以停靠、浮动、收起或关闭。拖动浮动面板标题可以移动；聚焦右下角手柄后可用方向键调整大小。窄屏时面板堆叠显示。紧凑的顶部导航始终提供“停止部署”；仅在重要警告或停止请求待确认时显示第二条顶部提示。普通消息五秒后消失，并留在日志的浏览器分区。即使 EOS 离线，也可以通过 IsOS 请求停止。

在控制面板调用原语后，切换页面、停靠或收起面板时，命令 ID 与所有者结果仍保留。点击“停止部署”会立即阻止本次运行的新调用和结果跟踪；停止结果不明时，界面不会显示为停止成功。关闭或收起监控与视觉面板会暂停轮询或视频流。日志面板停靠或收起时保留本次运行的不透明游标并暂停跟踪；关闭后重新打开会重新检查 IsOS 状态与日志范围。布局按机器人保存在本机，并限制在当前视口内。参见[工作面板契约](interfaces/workspace-panels_cn.md)。

查看所选 Vision 证据时，先等待 Home 报告当前运行就绪，再打开 Vision 面板。面板使用 IsOS 选择的 gate 与来源，订阅 EOS 公共 bridge，并显示运行、gate 代次、stream、JPEG 摘要、实际帧率和本地观察到的跳过代次。“尚无新画面”表示已证明的流就绪但尚未交付图像；“画面被拒绝”说明本地来源或摘要校验失败。停止、运行或修订变化、隐藏面板都会移除图像。参见 [Vision 来源契约](interfaces/workspace-panels_cn.md)。选定的 Q03 相机和合并后 Q04 final-5 Vision 回放均已通过；final-5 在回环地址模拟托管 Origin。
## 节点图加载

所选节点图与目录快照的修订一致后，节点图可以先显示；进程状态、就绪状态或软件包节点集仍可能在加载。点击**重新载入已保存节点图**会请求新快照；响应通过修订检查之前，原画布继续显示。首页每五秒只轮询进程状态；外部修改软件包或节点图后，点击**刷新**以重新加载完整的所有者视图。参见[节点图加载契约](interfaces/graph-loading_cn.md)。

## Q03 验证回放
