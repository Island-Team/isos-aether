# UI 节点边界

这些页面面向 IsosUI 的生产者与消费者。图为每个 UI 节点提供注册类型和类型化端口。IsOS 接收带运行栅栏的按钮激活，并通过声明的节点提供只读机械臂监控。

- [节点事件](node-events_cn.md)定义认证的按钮激活请求。
- [机械臂监控](node-monitor_cn.md)定义返回链和只读 UI 接口。
- [选择](selection_cn.md)定义 UI 选择输出展示方式时的编解码器、媒体、模式、负载与运行围栏检查。
- [呈现](presentation_cn.md)定义 UI 可展示的归属方描述符与输出身份；它不授予私有端点。
