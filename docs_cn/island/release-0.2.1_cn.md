# IsOS v0.2.1 仅源码 beta 发布说明

[English](../../docs/island/release-0.2.1.md) · [发布流程](release_cn.md) · [文档](../README_cn.md)

**状态：**仅源码 beta 预发布版本。**日期：**2026-11-10。

## 操作者可见的变化

这是源码版本为 `0.2.1` 的统一 IsOS、EI、EOS、Web 和 TUI 产品原生可测试源码快照，供开发与评估使用，属于 beta 阶段。当前演示使用图格式 `0.2.0` 以及已注册的 `isos`、`ei`、`eos` 节点类型。[首次使用指南](../isos/start/README_cn.md)描述受支持的配置、Apply、就绪、控制、日志和 Stop 路径。此次仅源码发布不包含预编译程序或产品安装程序。

## 支持的接口与兼容性

v0.2.1 是最早受支持的产品基线。不支持 v0.2.1 之前版本的代码、已保存图、软件包及接口；此次发布不提供旧版迁移路径。源码版本本身不能证明线协议兼容。当前图格式为 `0.2.0`，节点类型为 `@v0.2`；IsOS HTTP schema 为 `0.1.0`；软件包契约为 `isos.package@v1`，schema 为 `0.1.0`。准确支持的字段和所有者协议以 [IsOS](../isos/interfaces/README_cn.md)、[EI](../ei/interfaces/README.md) 和 [EOS](../eos/interfaces/README_cn.md) 契约为准。选定程序及软件包精确锁定仍须通过能力与验证检查。

v0.2.1 尚未完成面向第三方自定义节点的公开扩展契约。软件包声明和预留的实现字段不等于通用原生加载器或稳定的插件 ABI。内部 Rust 模块 API 可能在 v0.2.2 变化。依赖这些内部 API 的代码不属于 v0.2.1 支持的插件。

## 构建与评估

从公开 `Island-Team/isos-aether` 仓库检出不可变的 `v0.2.1` 标签。在已发布验证凭据列出的主机上，依照[源码快速开始](../isos/start/README_cn.md)运行 `./install_dev.sh`、`./isos doctor` 和 `./isos web`。从该标签构建与测试；v0.2.1 没有可通过 `isos upgrade` 安装的二进制下载。运行图之前检查软件包精确锁定和所有者就绪状态。评估结束后通过 IsOS 停止部署。

## 已知限制与后续计划

此 beta 目前仅在 Linux x86_64 上完成验证。它不提供稳定的自定义节点 SDK、通用 `.so` 加载器，也不声称支持跨平台构建。**目标设计——尚未实现：**计划在 v0.2.2 定义并验证自定义节点的打包、加载、生命周期和 Stop；计划在 v0.2.3 扩展受支持的主机平台。这些计划不保证依赖 v0.2.1 私有扩展代码的程序在后续版本中无需修改。

## 验证

GitHub 发布凭据记录准确的公开提交、实际测试的主机系统与架构、工具链版本、可复现命令及结果、端到端回放，以及所有未运行的门禁或已知失败。公开源码候选版本的严格 Clippy、工作区测试、锁定依赖的二进制构建、EOS CTest、EI 检查、UI 检查及双语文档审计均已通过。凭据会列出此 beta 尚未验证的边界。
